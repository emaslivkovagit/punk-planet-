Reflection on recreating page 40 using HTML

What was easy

The easiest parts of recreating the magazine page were setting up the basic structure using HTML tables and adding the text content. Creating the three-column layout with tables was straightforward once I understood how to use the width attributes and spacing cells. Adding background colors to match the newspaper aesthetic was also simple using the bgcolor attribute.

What was challenging

The most challenging aspect was getting the text to break at the exact same points as the original magazine page. Without CSS, controlling precise line breaks while having the text justified is really difficult. I had to adjust column widths multiple times to fit the right amount of words per line (although this did not work for all lines). Experimenting a lot to set the font sizes correctly.

What was not possible

Some design elements from the original page were impossible to replicate using only HTML. I could not create exact pixel-perfect line breaks, line spacing. The unique shapes in the middle of the page were impossible to recreate.
